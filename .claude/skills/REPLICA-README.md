# مهارات Replica

نسخة من https://github.com/Jakeschincariol/replica-skill (رخصة MIT، الرخصة في `REPLICA-LICENSE`).
مستخدمينها في أريفو عشان: تحليل التقييمات (replica-entrepreneur)، مقارنة الميزات (replica-recon + replica-diff)،
خطط الاختبار (replica-test)، فحص الهوية (replica-brand)، وصفحة الهبوط ووصف المتجر (replica-launch).
الملفات اللي بتطلعها المهارات بتتحفظ في فولدر `replica/` في المشروع.
