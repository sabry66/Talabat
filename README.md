# أريفو Arrivo 🛵

<img src="public/img/logo.png" alt="أريفو" width="120">

منصة توصيل أكل كاملة (عملاء، مطاعم، مندوبين، وأدمن)، ببلاش بالكامل على Firebase.

- **تطبيق العميل:** بحث، تصنيفات، منيو، سلة، أكواد خصم، قسم "🔥 عروض وخصومات"، تحديد العنوان على الخريطة (الدبوس ثابت في النص + بحث عن مكان + موقعي الحالي + ملء الشاشة)، وتتبع الطلب لحظيًا.
- **اشتغل معانا:** قسم في آخر الرئيسية وفي القايمة الجانبية لتسجيل المطاعم والمندوبين، وسؤال "إنت مين؟" في الحساب الجديد، ولينكات قصيرة للنشر: `/join/restaurant` و`/join/driver` و`/join`.
- **لوحة المطعم:** الطلبات بتوصل بصوت تنبيه، قبول ورفض و"جاهز للتسليم"، تعديل المنيو والأسعار وحذف الأصناف، تبويب "العروض والخصومات" (خصم % أو سعر جديد على أي صنف ولحد تاريخ معين + عرض عام على المطعم)، صور الأصناف ولوجو المطعم، وفتح وقفل المطعم.
- **صفحة المندوب:** الأوردرات المتاحة بتنبيه، مكان الاستلام والتسليم على الخريطة، المبلغ اللي هيحصّله ومكسبه، وسجل أوردراته.
- **لوحة الأدمن:** الحسابات (ربح المنصة، وحق كل مطعم وكل مندوب بأرقام الأوردرات)، مناطق التوصيل وأسعارها، النسب، المطاعم، المندوبين، والطلبات.

## التجربة السريعة (من غير Firebase)

```bash
python3 -m http.server 8000 -d public
```

افتح http://localhost:8000. لو `apiKey` فاضي في `public/js/firebase-config.js`، التطبيق هيشتغل في وضع تجريبي بحسابات جاهزة (كلمة السر لكلهم `123456`):

| الحساب | الصفحة |
|---|---|
| `customer@demo.com` | `/` |
| `owner@demo.com` | `/restaurant.html` |
| `driver@demo.com` | `/delivery.html` |
| `admin@demo.com` | `/admin.html` |

افتح كل حساب في تاب لوحده، وجرّب تطلب من تاب العميل وتستقبل الطلب في تاب المطعم.

## التقنيات (كلها مجانية)

- HTML و CSS و JavaScript من غير أي framework ومن غير build step.
- Firebase Authentication لتسجيل الدخول.
- Cloud Firestore لقاعدة البيانات اللحظية.
- Firebase Hosting للاستضافة.
- Leaflet + OpenStreetMap للخريطة.
- Cloudinary لصور المطاعم والأصناف.
- خط Cairo جوه المشروع في `public/fonts` (رخصة OFL المجانية)، فمش محتاج Google Fonts.
