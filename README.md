# طلباتي 🛵

تطبيق ويب لطلب الأكل والتوصيل، شبه "طلبات". مبني بـ HTML و CSS و JavaScript من غير أي مكتبات خارجية.

## التشغيل

افتح ملف `index.html` في المتصفح مباشرة، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
# وبعدين افتح http://localhost:8000
```

## المميزات

- **الرئيسية:** بحث بالمطعم أو الأكلة، تصنيفات (برجر، بيتزا، شاورما...)، وترتيب حسب التقييم أو سرعة التوصيل أو رسوم التوصيل.
- **صفحة المطعم:** المنيو مقسّم أقسام، إضافة أصناف وتعديل الكمية، وسلة جانبية.
- **السلة:** مطعم واحد لكل طلب (زي طلبات)، حد أدنى للطلب، أكواد خصم (`TALABAT20` و `WELCOME50` و `FREEDEL`)، ورسوم توصيل وخدمة.
- **إتمام الطلب:** العنوان، رقم الموبايل، ملاحظات، وطريقة الدفع.
- **تتبع الطلب:** مراحل الطلب (استلام ← تحضير ← في الطريق ← تم التوصيل) بتتحدث تلقائيًا (مُسرّعة للعرض).
- **طلباتي:** سجل الطلبات السابقة مع زر "اطلب تاني".
- تصميم متجاوب للموبايل، والبيانات بتتحفظ في المتصفح (localStorage).

## هيكل المشروع

```
index.html      الصفحة الرئيسية
css/style.css   التصميم
js/data.js      بيانات المطاعم والمنيو وأكواد الخصم
js/store.js     إدارة السلة والطلبات والحفظ
js/app.js       الصفحات والتنقل
```

## الخطوات الجاية المقترحة

- باك إند (Node.js / Firebase) لحفظ المطاعم والطلبات بدل البيانات الثابتة.
- تسجيل دخول للمستخدمين، ولوحة تحكم للمطاعم لاستقبال الطلبات.
- دفع إلكتروني فعلي، وتتبع المندوب على الخريطة.
